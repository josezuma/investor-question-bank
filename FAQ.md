# FAQ

## What is investor-question-bank?
200+ YC partner questions organized by slide. Know what investors will ask before they ask it.

## How do I install it?
```bash
git clone https://github.com/josezuma/investor-question-bank.git && cd investor-question-bank
```

## Is this compatible with yc-pitch-deck-max?
Yes. investor-question-bank integrates directly with yc-pitch-deck-max.

## Do I need any external dependencies?
No. All scripts use only Python stdlib.
